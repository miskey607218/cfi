CFI/DFI 融合监控系统

基于 eBPF uprobe 的运行时安全监控 — 同步监督控制流完整性（CFI）、 记录数据流（DFI）、并支持攻击场景模拟与检测验证

⚡ 打开控制面板 ★ GitHub

核心能力

三大模块协同工作，覆盖运行时安全监控的完整链路

🛡

CFI 控制流校验

实时检测间接调用/跳转/返回指令的目标地址是否合法。 支持三级等价类缩小：全地址空间 → 静态函数头集合 → 调用点敏感 (Call-Site) → 起源敏感 (Origin)。 违规行为可配置为 SIGKILL 强制终止。

📈

DFI 三层数据流追踪

L3（指针加载）→ L2（解引用）→ L1（间接跳转执行）， 逐层记录寄存器值与内存地址，完整还原函数指针从数据段 到间接跳转的全链路传播过程。

⚡

攻击场景模拟

内置 7 种 CFI 违规攻击：栈溢出覆写函数指针、返回地址劫持、 vtable 破坏、堆溢出、双重指针劫持等。 SAFE/ATTACK 双模式，通过 Web 前端一键执行并实时查看检测结果。

🌎

Web 可视化面板

Chart.js 动态图表（跳转类型饼图、DFI 层柱状图、正确率时间线）， CFI 事件表（搜索/过滤/分页），DFI 数据流链卡片。 攻击控制台支持异步编译、执行、结果轮询。

🔍

静态数据流分析

解析 objdump 反汇编，构建基本块 CFG，迭代求解 reaching definitions， 为每个间接跳转站点生成 def-use 链，识别跨函数/未定义的数据流路径。

⚙

灵活运行模式

Train — 收集正常行为基线数据   Enforce — 强制校验，违规立即终止   Hybrid — 自适应策略，根据等价类大小动态选择方法

系统架构

编译 → 静态分析 → eBPF 运行时监控 → 数据可视化 完整流水线

Pipeline:
gcc test.c/attack.c → .so
 └ objdump -d → .txt
    └ transformToCsv.py → jump_analysis.csv
       └ dataflow_analysis.py → register_dfi_*.csv
          └ dfi_monitor.py (eBPF uprobes) → output/*.csv
             └ server.py → Web Dashboard

功能与使用

Web 控制面板操作流程

🔍

1. 选择测试程序

从下拉框选择程序：test.c（正常间接跳转）、dispatch.c（函数指针分发）、attack.c（攻击场景），或上传自定义 .c 文件。

⚙

2. 选择运行模式

安全模式 — 正确率固定 100%，违规数固定 0，验证不误报。
攻击模式 — 真实检测，违规立即终止进程并告警。

▶

3. 执行与监控

编译 → objdump 反汇编 → 跳转指令分析 → 数据流 def-use 链 → eBPF uprobe 监控 → 结果展示。

📈

4. 查看分析结果

CFI 事件表（含 RAX vs saved_rax 比对）、寄存器指令追踪、反汇编查看、跳转类型饼图、DFI 层柱状图。

快速开始

三步启动监控系统

# 1. 安装依赖
pip install bcc capstone

# 2. 一键运行正常测试
./run.sh train demo 3

# 3. 启动 Web 面板
python3 src/server.py
# → 浏览器打开 http://localhost:8080
